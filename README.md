# CleanVision — AI Bathroom Cleanliness Inspection & Auditing System

Developed an AI-powered computer vision system to assess bathroom cleanliness and sanitation compliance from images. CleanVision features in-browser edge neural network evaluation (`onnxruntime-web`), automated hygiene scoring, and a modern progressive web application (PWA) with QR visitor feedback.

🌐 **Live Demo:** [cleanvision-ai-puce.vercel.app](https://cleanvision-ai-puce.vercel.app)

---

## ✨ Features

- 🧠 **Computer Vision & ONNX Inference**: Real-time neural network inference evaluating floor cleanliness, stains, mud, and debris.
- ⚡ **In-Browser WebAssembly Acceleration**: Powered by `onnxruntime-web` for instant offline and edge AI execution.
- 📱 **Progressive Web App (PWA)**: Works seamlessly across desktop, tablets, and mobile devices with camera support.
- 📊 **Facility Management Dashboard**: Inspection logs, trend charts, supervisor audit reports, and PDF print exports.
- 🏥 **Public QR Feedback Portal**: Visitors and patients can scan QR codes to report cleanliness alerts directly to housekeeping.

## 🚀 Quick Start

### 1. Installation
```bash
npm install
cd frontend && npm install
```

### 2. Development Mode
```bash
# Run both backend server and frontend Vite app
npm run dev
```

### 3. Production Build
```bash
npm run build
```
